## 1. 2.1.27 首版为什么像 B

2.1.27 首版用“整段译文必须是已播前缀”做去重。  
实际 partial 译文改写很多，例如：

```text
你来自哪里？你这个周末有什么安排？
你来自哪里？这个周末有什么安排？在你所在的城市……
```

整段前缀对不上，就一直不播，直到 final 才一次性补，所以听感像 B。

## 2. 2.1.28 的修正

改成 **中文块级稳定 + 顺序播报**：

- 英文 partial 仍然整段不切；
- 整段翻译成中文；
- 中文按 `，。！？；、：` 切块；
- 按块顺序处理：
  - 已播块跳过；
  - 遇到第一个“还不稳定的未播块”就停；
  - 不越序播后面的块；
- 一个块在上一版 partial 译文里也出现，才算稳定；
- final 到达时，不再要求稳定，剩余块和尾巴全部补播。

这样：

- 不会把 `你们是中文字幕组的成员吗？` 这种一次性误译播出去；
- 也不会因为整段译文改写就整句等到 final；
- `Chinese subtitles` 不会再被切成“中国人 / 字幕”。

## 4. 测试

1. 安装 2.1.28，覆盖 2.1.27。
2. 设置：
   - 中文字幕语音播报：开
   - LCT 式增量播报：开
   - 对方原音：30
3. 短版 5 段，同音量/位置/顺序，等 ASR 启动后再播。
4. 重点看：
   - 是否在 final 前就有多段中文 TTS；
   - `Chinese subtitles` 是否完整；
   - 是否还有 `你们是中文字幕组的成员吗？` 被播；
   - `tts zh gate` 最大/中位；
   - 第 5 段是否出字幕；
   - 有没有重复/漏句。
5. 日志：
   ```text
   inc tts zh chunk
   inc tts hold unstable
   inc tts final tail
   tts zh gate
   ```
